Using Tracker Online: To maximize Tracker, click the blue up-facing triangle at the right end of the toolbar. To open a Tracker project (TRZ), Tracker tab (TRK), or video file:

  • Drag and drop the file from your desktop onto Tracker Online.
  • Or download or copy the file to your desktop, choose File|Open File and select the file.
  • Or choose File|Open Library Browser, choose a collection from the Collections menu, browse to a resource of interest and double-click the resource.

Supported Videos: Tracker Online can open the following types of videos:

  • Image stacks consisting of JPEG or PNG images numbered sequentially (e.g. car00.jpg, car01.jpg, car02.jpg, ...). Image stacks may be in a ZIP file.
  • Video types supported by HTML5, such as MP4 with H264 codec.
  • Videos captured directly from your camera. To capture a video, choose Video|Capture.

For unsupported videos we recommend converting them to mp4 using the open source application HandBrake, available for Windows, Linux and MacOS platforms. Choose the default "Fast 1080p30" preset, then in the Video tab choose "Constant Framerate". If you prefer, you can use a web-based converter such as Cloud Convert. To create image stacks we recomment Online Converter.

Tracker Projects with Unsupported Videos: A Tracker Project is a ZIP file with extension TRZ that contains video files, Tracker tab files (TRK), and documentation files (HTML, PDF). Some Tracker Projects may contain unsupported videos such as MOV or AVI. These can be opened in Tracker Online but they will not display the video. To fix this, you can unzip the TRZ file, find the video and convert it to a supported format as described above, then copy it to your desktop and import it back into the tab using Video|Import.

Bug Reporting: Use the Tracker Online Bug Report form to report bugs you discover in Tracker Online. Use the OSP Tracker Discussion forum for all other Tracker related questions or feedback. We welcome questions about how to use Tracker, suggestions for additional Tracker features, and bug reports related to the desktop or online version of Tracker.
