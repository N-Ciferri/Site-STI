      Correspondance pseudo-code · blocs · Python
      
    
        
    
          
    Pseudo-codeBlocPython
    
          
    x ← valeur« mettre x à »x = valeur
    
          
    LIRE(x)« mettre x à » + « demander … et attendre un nombre »x = int(input("..."))
    
          
    ECRIRE(x)« afficher »print(x)
    
          
    SI … ALORS … SINON … FINSI« si … alors … sinon »if … : / else:
    
          
    SINON SI« sinon si »elif … :
    
          
    TANT QUE … FAIRE … FINTANTQUE« répéter tant que »while … :
    
          
    ALEATOIRE(1,100)« nombre aléatoire entre 1 et 100 »random.randint(1, 100)
    
          
    x ← x + 1« ajouter 1 à x »x = x + 1
    
        
    
        
    En Python, il n'y a pas de FINSI ni de FINTANTQUE : c'est l'indentation (4 espaces en début de ligne) qui indique quelles lignes font partie du « si » ou du « tant que ».
    
      
    
    
    

    
    
      Les symboles de l'organigramme
      
    
        
    
          
    SymboleSignification
    
          
    ⬭ ovaleDébut ou fin de l'algorithme.
    
          
    ▱ parallélogrammeEntrée (lire une donnée) ou sortie (afficher).
    
          
    ▭ rectangleTraitement : un calcul, une affectation.
    
          
    ◇ losangeDécision : une question à réponse oui / non, avec deux flèches de sortie.
    
        
    
        
    Dans l'onglet « Organigramme », une boucle « tant que » est dessinée avec un losange : la flèche « oui » entre dans la boucle, la flèche de retour remonte avant le losange, et la flèche « non » sort de la boucle.
    
      
    
    
    

    
    
      Conseils pour tester
      
    
        
      
          
    • Cochez le mode test en haut de la page : le nombre « aléatoire » prend la valeur choisie. Vous pouvez alors vérifier les trois cas : proposer plus petit, plus grand, puis le bon nombre.
      • 
          
    • Quand le programme pose une question, tapez la réponse dans la zone « Résultat » puis appuyez sur Entrée. Le bouton « ■ Arrêter » interrompt le programme.
      • 
          
    • Si un programme tourne en boucle sans fin, il est arrêté automatiquement et un message vous l'indique.
      • 
          
    • « TANT QUE trouve = FAUX » s'écrit en Python while not trouve:. Les deux idées « trouvé = faux » et « pas trouvé » sont les mêmes.
      • 
          
    • Les noms de variables s'écrivent sans espace ni accent : nombre_secret, nb_essais, trouve.
      • 
          
    • Votre travail est gardé dans ce navigateur. Pour le conserver ailleurs, utilisez « Enregistrer ».
