Les types de données : int, float, str, bool

Chaque valeur a un type. Le type décide de ce qu'on peut faire avec la valeur.

TypeCe que c'estExemples
intnombre entier (positif ou négatif)12 -3 0
floatnombre à virgule (on écrit un point, pas une virgule)3.14 -0.5 2.0
strchaîne de caractères : du texte"Bonjour" "STI2D" 'A'
boolbooléen : vrai ou fauxTrue False
listliste de valeurs[12, 15, 9]

type(valeur) donne le type d'une valeur.

print(type(12))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("Bonjour")) # <class 'str'>
print(type(True))      # <class 'bool'>
print(type(5 > 3))     # une comparaison donne un bool

Convertir d'un type à l'autre :

FonctionExempleRésultat
int(...)int("42"), int(3.9)42, 3 (coupe la partie décimale)
float(...)float("12.5"), float(7)12.5, 7.0
str(...)str(42)"42"
bool(...)bool(0), bool(5)False, True
Écrire les valeurs : guillemets, apostrophes, nombres
  • Une chaîne de caractères (du texte) s'écrit entre guillemets : "Bonjour", "Serre n°1".
  • Un caractère seul s'écrit entre apostrophes : 'A', '7', '?'.
  • Un nombre s'écrit sans rien autour : 42, 3.14.
  • True et False s'écrivent sans guillemets, avec une majuscule.
En Python, 'A' et "A" sont en réalité identiques : ce sont deux chaînes de type str. On garde quand même l'habitude des apostrophes pour un caractère seul, car en C++ et sur Arduino elle est obligatoire.

Piège : "42" (entre guillemets) est du texte, pas un nombre.

print(42 + 8)       # 50 : addition de deux nombres
print("42" + "8")   # 428 : collage de deux textes
print("42" * 3)     # 424242
print(int("42") + 8)  # 50 : on convertit d'abord le texte en nombre

Pour mettre une apostrophe dans un texte, utilisez des guillemets autour : "l'entrée".

Afficher : print()

print(...) affiche des valeurs dans la zone Résultat, puis passe à la ligne.

  • Le texte se met entre guillemets, les nombres et les variables sans guillemets.
  • On sépare plusieurs valeurs par des virgules : Python ajoute un espace entre elles.
temperature = 23.5
print("Bonjour")
print("Température :", temperature, "°C")
print("La lettre", 'A', "et le nombre", 7)
print(2 + 3)          # affiche 5
print("2 + 3")        # affiche le texte 2 + 3

Deux options utiles :

  • sep="..." change le séparateur entre les valeurs ;
  • end="..." change ce qui est écrit à la fin (par défaut, un retour à la ligne).
print(12, 5, 2025, sep="/")    # 12/5/2025
for i in range(5):
    print(i, end=" ")           # 0 1 2 3 4 sur une seule ligne

Avec un f devant les guillemets, on peut placer des variables entre accolades { } :

nom = "Léa"
note = 15.5
print(f"{nom} a eu {note}/20")
Demander une valeur : input()

input("question") affiche la question (entre guillemets) et attend la réponse de l'utilisateur.

input() renvoie toujours une chaîne de caractères (str), même si on tape un nombre. Pour calculer, il faut convertir avec int(...) ou float(...).
prenom = input("Ton prénom ? ")            # texte : pas de conversion
age = int(input("Ton âge ? "))             # nombre entier
taille = float(input("Ta taille en m ? ")) # nombre à virgule (avec un point)

print("Bonjour", prenom)
print("Dans 10 ans, tu auras", age + 10, "ans")
print("Taille en cm :", taille * 100)

✗ Sans conversion, Python colle des textes ou refuse le calcul :

age = input("Ton âge ? ")
print(age + 10)   # erreur : on ne peut pas ajouter un nombre à un texte
Les fonctions : def

Une fonction regroupe des instructions sous un nom, pour pouvoir les réutiliser. On la crée avec le mot-clé def devant son nom :

  • def, puis le nom, puis les paramètres entre parenthèses, puis deux-points : ;
  • les instructions de la fonction sont indentées (4 espaces) ;
  • return renvoie le résultat de la fonction ;
  • la fonction doit être définie avant d'être appelée.
def aire_rectangle(longueur, largeur):
    aire = longueur * largeur
    return aire

# appel de la fonction
resultat = aire_rectangle(4, 2.5)
print("Aire :", resultat, "m²")
print("Autre aire :", aire_rectangle(3, 3))

Une fonction peut aussi ne rien renvoyer et seulement afficher :

def saluer(prenom):
    print("Bonjour", prenom, "!")

saluer("Léa")
saluer("Tom")

✗ Erreurs fréquentes : oublier les : après la parenthèse, oublier l'indentation, ou appeler la fonction sans parenthèses (saluer au lieu de saluer("Léa")).
