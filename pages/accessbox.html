AccessBox

Vérifiez vos conversions binaire / hexadécimale, puis construisez le logigramme de la règle d'accès en assemblant des portes ET, OU et NON.

Vérifier une conversion

Reprenez un code de l'AccessBox (ou tirez-en un nouveau), convertissez-le vous-même sur votre feuille, puis contrôlez vos réponses ici.

Construire le logigramme

Faites glisser une porte sur le plan de câblage (ou cliquez dessus). Cliquez sur une borne de sortie puis sur une borne d'entrée pour les relier. Cliquez sur une porte ou un fil pour le sélectionner, puis Suppr pour l'enlever.

Règle à câbler : l'Ouverture vaut 1 si (C = code correct OU B = badge détecté) ET N = mode nuit vaut 0.
